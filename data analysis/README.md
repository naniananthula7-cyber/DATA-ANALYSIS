# E-commerce Sales Analysis 📊

This project performs exploratory data analysis (EDA) on synthetic e-commerce sales data.  
It covers revenue trends, customer segmentation (RFM), top products, and geographic performance.

## Features
- Dataset overview and cleaning
- Sales by category
- Monthly revenue trends
- Customer segmentation (RFM analysis)
- Top products by revenue
- Geographic market analysis
- Growth metrics dashboard

## Project Structure
- `data/sales_data.csv` → Sample dataset
- `src/main.py` → Main analysis script
- `notebooks/eda.ipynb` → Optional Jupyter notebook
- `requirements.txt` → Dependencies
